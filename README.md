# AI 엔진 조합 내비게이터

분야별 인기 AI 엔진 Top 10(10개 분야 · 100개)을 **Claude 협업도** 순으로 정리하고, 프롬프트를 입력하면 Claude와 함께 쓸 최적의 AI 조합을 작업 순서대로 추천하는 인터랙티브 사이트입니다. (2026년 11월 조사 기준)

- `index.html` — 사이트 본체 (① 조합 추천 · ② 분야별 Top 10 · ③ 전체 협업 순위 · ④ 순위 산정 방식)
- `practice/` — 엔진별 연습실 97개 + 허브(`practice/index.html`). 공통 프레임워크 `practice/assets/`, 엔진별 미션 `practice/content/<분야>.js`, 폴더 생성 스크립트 `practice/build.js`
- `data.js` — 엔진 데이터(주요 기능·사용료·Claude 연동 방식·점수)와 작업 유형 키워드
